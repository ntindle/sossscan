# Contact

sossscan is a spare-time project with one maintainer, Nick Tindle, so replies can take a while.

## Email

For questions about the site, the guide or the GitHub App, or anything that doesn't fit a public issue, write to [sossscan@ntindle.com](mailto:sossscan@ntindle.com). Please report security problems through GitHub instead, as described below.

## Bugs and ideas

Open an issue on GitHub at [github.com/ntindle/sossscan/issues/new](https://github.com/ntindle/sossscan/issues/new). For a wrong result, include the repository you scanned, the name of the check and what you expected it to say. To suggest a change to a check's text or structure, open an issue, or a pull request that changes the repository's build/ folder. The maintainer rebuilds the guide from it.

## Security problems in sossscan

Please don't report a vulnerability in sossscan in a public issue, discussion or pull request. Report it privately through GitHub instead, at [github.com/ntindle/sossscan/security/advisories/new](https://github.com/ntindle/sossscan/security/advisories/new). Say what you found, how to reproduce it, and what someone could do with it.

That covers the scanner and the downloadable CLI, this site and its API, and the GitHub App, including how the server uses the app's permissions. If the app did anything to a repository that nobody asked for, report that too. A problem the scanner finds in someone else's repository belongs to that project, so report it to them. The known limitations listed in the README are out of scope.

The aim is to acknowledge a report within a week, keep you posted while it's being fixed, and credit you in the advisory unless you'd rather not be named. There's no bug bounty. The full policy is in [SECURITY.md](https://github.com/ntindle/sossscan/blob/main/SECURITY.md).

## The GitHub App

The app is at [github.com/apps/sossscan](https://github.com/apps/sossscan). You choose the repositories it's installed on, and you can uninstall it from your GitHub settings at any time. The README explains [what each of its permissions is used for and what it never does](https://github.com/ntindle/sossscan#the-github-app).
